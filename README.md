# فروشگاه من

پنل وب + اپ اسکنر گوشی. داده، ورود، فاکتور و انبار روی **سوپابیس** است.

- **وب** (`apps/web`): Next.js — مدیریت، فاکتورها، **چاپ فاکتور**
- **اسکنر** (`apps/scanner`): Vite PWA — گوشی: اسکن اقلام → «ثبت فاکتور»
- **دیتابیس و ورود**: Supabase (Postgres + Auth + Realtime)

جریان اصلی روزانه:

```
📱 گوشی: اسکن بارکد → اقلام در «سبد فاکتور» جمع می‌شوند → «ثبت فاکتور»
        ↓ (ریل‌تایم — همان لحظه)
💻 لپ‌تاپ: بخش «فاکتورها» → دکمه‌ی چاپ → رسید برای مشتری
```

## شروع سریع

```bash
pnpm install
cp apps/web/.env.example apps/web/.env.local     # کلیدهای سوپابیس
pnpm db:seed                                     # حساب نمونه (یک‌بار)
pnpm dev                                         # وب :3000 — اسکنر :5173
```

| ایمیل | رمز | نقش |
|---|---|---|
| `admin@mystore.ir` | `123456` | مدیر — تنظیمات، قیمت، کاربران، حسابداری |
| `cashier@mystore.ir` | `123456` | صندوق‌دار — فروش، اسکن، مشتری |

## راه‌اندازی سوپابیس (یک‌بار)

1. یک پروژه در [supabase.com](https://supabase.com) بسازید.
2. **SQL Editor**: فایل `supabase/migrations/0001_init.sql` را کامل اجرا کنید.
3. **SQL Editor**: فایل `supabase/migrations/0002_realtime.sql` را کامل اجرا کنید
   (ریل‌تایم گوشی ↔ وب؛ بدون آن هم کار می‌کند ولی با پولینگ ۳ ثانیه‌ای).
4. **Authentication → Providers → Email** را روشن و «Confirm email» را خاموش کنید.
5. **Project Settings → API Keys** و کلیدها را در `apps/web/.env.local` بگذارید:

| متغیر | توضیح |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | آدرس پروژه |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | کلید publishable (مرورگر/ورود) |
| `SUPABASE_SECRET_KEY` | کلید محرمانه — فقط سرور؛ هرگز `NEXT_PUBLIC_` ندهید |

نام‌های قدیمی `NEXT_PUBLIC_SUPABASE_ANON_KEY` و `SUPABASE_SERVICE_ROLE_KEY` هم پشتیبانی می‌شوند.

## عیب‌یابی: صفحه‌ی `/setup`

اگر جایی گیر کرد (ورود نمی‌شود، فاکتور نمی‌آید، صفحه خطا می‌دهد)، آدرس
`/setup` را باز کنید. این صفحه بدون ورود کار می‌کند و مرحله‌به‌مرحله می‌گوید:

- کدام متغیر محیطی کم است (روی ورسل هم برای محیط Production)
- اتصال به سوپابیس برقرار است یا نه
- اسکیمای `0001` اجرا شده یا نه
- ریل‌تایم `0002` روشن است یا نه
- حساب مدیر ساخته شده یا نه

هر مورد راه‌حل کوتاهش را هم نشان می‌دهد.

## اسکنر (گوشی)

```bash
pnpm dev:scanner      # http://localhost:5173
```

- فهرست کالاها یک‌بار روی گوشی کش می‌شود؛ به همین دلیل هر اسکن **بدون**
  انتظار برای اینترنت انجام می‌شود.
- هر اسکن با نوع `CART` ثبت می‌شود (موجودی را عوض نمی‌کند) تا پنل وب
  «در حال اسکن» را زنده ببیند.
- «ثبت فاکتور» یک فاکتور واقعی می‌سازد: موجودی کم می‌شود، مالیات از
  تنظیمات فروشگاه حساب می‌شود و پرداخت (نقدی/کارت/نسیه) ثبت می‌شود.
- سبد روی گوشی ذخیره می‌شود؛ رفرش یا قفل‌شدن صفحه اقلام را از بین نمی‌برد.

استقرار روی ورسل: [`DEPLOYMENT.md`](DEPLOYMENT.md).

## نقش‌ها

**مدیر:** نام فروشگاه، مالیات، قیمت خرید و فروش، حذف کالا، هزینه، خرید، دفتر کل، گزارش سود، کاربران، بارکد، لغو فاکتور.

**صندوق‌دار:** دیدن کالا بدون قیمت خرید، جست‌وجو و فیلتر، صدور فاکتور با قیمت قفل‌شده، اسکن فروش/شمارش/سبد، ثبت پرداخت.

## صفحه‌ها

داشبورد، محصولات، مشتریان، فاکتورها (+چاپ)، خرید، هزینه، دفتر کل، گزارش سود، حرکت انبار، تنظیمات، کاربران، اسکنر، و `/setup` برای راه‌اندازی.
