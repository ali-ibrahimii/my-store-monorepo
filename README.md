# فروشگاه من

پنل وب و اپ اسکنر بارکد. داده، فاکتور، انبار، حسابداری و ورود روی **سوپابیس** است. اپ موبایل جدا حذف شده.

- **وب:** Next.js — مدیر و صندوق‌دار
- **اسکنر:** Vite PWA — همان API وب، با توکن سوپابیس
- **دیتابیس و ورود:** Supabase Auth + Postgres

## راه‌اندازی سوپابیس

1. یک پروژه در [supabase.com](https://supabase.com) بسازید.
2. SQL Editor را باز کنید و کل فایل `supabase/migrations/0001_init.sql` را اجرا کنید.
3. در Authentication → Providers ایمیل را روشن کنید و تأیید ایمیل را خاموش کنید تا ورود همان لحظه کار کند.
4. در Authentication → Settings مدت JWT را اگر خواستید طولانی‌تر کنید (پیش‌فرض یک ساعت است).
5. از Project Settings → API Keys آدرس و کلیدها را در `apps/web/.env.local` بگذارید:

```bash
cp apps/web/.env.example apps/web/.env.local
```

| متغیر | توضیح |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | آدرس پروژه |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | کلید publishable برای ورود و دسترسی مرورگر |
| `SUPABASE_SECRET_KEY` | کلید محرمانه‌ی سرور برای API و seed؛ هرگز با `NEXT_PUBLIC_` تعریف نکنید یا در مرورگر نگذارید |

نام‌های قدیمی `NEXT_PUBLIC_SUPABASE_ANON_KEY` و `SUPABASE_SERVICE_ROLE_KEY` هم پشتیبانی می‌شوند. کلید publishable جای کلید secret/service role را نمی‌گیرد.

6. داده و حساب نمونه:

```bash
pnpm install
pnpm db:seed
pnpm dev:web
```

| ایمیل | رمز | نقش |
|---|---|---|
| `admin@mystore.ir` | `123456` | مدیر — تنظیمات، قیمت، کاربران، حسابداری |
| `cashier@mystore.ir` | `123456` | صندوق‌دار — فروش، اسکن، مشتری |

اسکنر:

```bash
pnpm dev:scanner
```

## نقش‌ها

**مدیر:** نام فروشگاه، مالیات، قیمت خرید و فروش، حذف کالا، هزینه، خرید، دفتر کل، گزارش سود، کاربران، بارکد، لغو فاکتور.

**صندوق‌دار:** دیدن کالا بدون قیمت خرید، جست‌وجو و فیلتر، صدور فاکتور با قیمت قفل‌شده، ثبت مشتری در دیالوگ، اسکن فروش/شمارش، ثبت پرداخت. تنظیمات، سود، هزینه و تغییر قیمت ندارد.

## صفحه‌ها

داشبورد، محصولات (جست‌وجو، دسته، کم‌موجود، دیالوگ افزودن)، مشتریان (دیالوگ)، فاکتور، خرید، هزینه، دفتر کل، گزارش سود و پرفروش‌ها، حرکت انبار، تنظیمات، کاربران، اسکنر.
